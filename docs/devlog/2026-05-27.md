- **MuxPlayer React component** — bloqueado por CSP. Web component directo tampoco. Solución final: `<video>` nativo + hls.js.
- **Video proxy** (`/api/video-proxy`) — workaround parcial. Causa raíz: **CSP en `next.config.ts`** sin dominios de Mux (`stream.mux.com`, `fastly.mux.com`). Corregido el CSP, proxy innecesario.
- **Descarga directa desde Google Drive vía script** — `&confirm=t` no alcanza para >100MB. 5 assets quedaron "Errored". Limpiados, descarga manual vía browser.
- **Supabase Storage como intermediario para videos** — límite 50MB/archivo, videos de 4-10GB.
- **Contraseña temporal para onboarding** — implementada inicialmente. El usuario cambió al ver diseño: prefiere invite link. Reemplazada por `generateLink`.
- **libx264 para compresión** — demasiado lento. `h264_videotoolbox` (hardware Apple Silicon) 10-20x más rápido.
