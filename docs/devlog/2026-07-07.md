# 2026-07-07

## Sesión 16:04

### Contexto
Error 502 al iniciar la subida a Mux desde "Repetición de la clase" (grabar clase en vivo de Rentix). La UI mostraba el mensaje genérico "No se pudo iniciar la subida a Mux" y la sospecha inicial era que fallaba por el entorno de Capacitación Comercial CI.

### Lo que se hizo
- Se reprodujo la llamada real a `mux.video.uploads.create()` con las credenciales locales (script scratch, no comiteado) para ver el error verdadero de Mux en vez de especular.
- Causa raíz identificada: la cuenta de Mux está en **plan gratuito con tope de 10 assets, lleno (10/10)**. Mux rechaza cualquier `uploads.create` con "Free plan is limited to 10 assets…" y el route lo enmascara tras el mensaje genérico.
- Se listaron los 10 assets y se cruzaron sus `playback_id` contra la tabla `lessons` (Supabase): 7 son clases reales, 3 huérfanos (0 min y 2 min de prueba + 1 duplicado de 127 min de "Educación Financiera" sin enlazar).
- Fix operacional elegido por el usuario: **borrar los 2 assets de prueba** (0 y 2 min) vía API de Mux → cupo liberado a 8/10. Se verificó que `uploads.create` vuelve a funcionar. El duplicado de 127 min se dejó intacto.
- Commit + push del devlog del 6-jul pendiente (`387758a`, `docs`) a `work/main`.

### Lo que se descartó
- **Hipótesis del entorno como causa**: descartada. El código de subida no tiene ningún check por tenant; el fallo ocurre en cualquier entorno, fue casualidad tocarlo desde Capacitación Comercial.
- **Push a `origin`**: falló. `origin` apunta a `elkisdm/Capitalacademy` y la cuenta `edaza-create` no tiene permiso. El remote correcto para desplegar es `work` (`edaza-create/capitalacademy`) → Netlify.
- **Borrar el duplicado de 127 min**: no se hizo; queda como candidato seguro si se necesita un tercer slot.
- No se tocó código en la sesión (el fix fue puramente operacional sobre la API de Mux).

### Pendientes / dudas abiertas
- **Reencontrar el límite pronto**: con 8/10 y más grabaciones por venir, borrar huérfanos es un parche. El fix definitivo es subir Mux a plan pagado (decisión de negocio/costo).
- **Mejorar el mensaje de error**: `app/api/admin/mux/upload/route.ts` esconde el motivo real de Mux. Se propuso propagar el mensaje real al admin (cambio chico, vía spec-flow); quedó sin hacer — el usuario pidió solo commit y push.
